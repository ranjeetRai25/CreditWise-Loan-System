# CreditWise Loan System

## Problem Statement

SecureTrust Bank receives hundreds of loan applications daily through online and branch channels.
Currently, the bank uses a manual verification process that is:

Time-consuming
Biased and inconsistent
Prone to human error

This creates two major business problems:

Good customers may get rejected
High-risk customers may get approved

To solve this issue, this project builds an ML-powered Loan Approval Prediction System that helps automate the decision-making process.
